## [0.7.0] - 2026-08-02

### Added
- **Deployment Specification**: Created `DEPLOYMENT.md` providing step-by-step setup guides for Vercel (Next.js client) and AWS App Runner (FastAPI containers).
- **Environment variables checklist**: Formulated production variables tables for frontend and backend modules.
- **Pre-deployment Testing Checklist**: Drafted verification test targets (CORS, file uploads, OCR, voice stream playback, local boundary scope).
- **Project Roadmap**: Added roadmap mapping Phase 1 to Phase 3 (Digital Twin mapping).
